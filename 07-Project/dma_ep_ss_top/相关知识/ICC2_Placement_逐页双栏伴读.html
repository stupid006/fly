使用说明

本次全篇扩充。技术页增加关键内容的中文释义、术语对照、机制说明与自拟案例；有命令的页面增加参数表。目录、过渡及空白页按实际内容说明。

打开原文。将 HTML 下载到电脑，用 Edge 或 Chrome 打开，点击“选择原 PDF”，选择原来的 126 页讲义。原 PDF 不包含在本文件中，也不会被上传或改写。

翻页对照。上方页码和目录切换讲解，并请求左侧阅读器跳到同页。浏览器阅读器行为可能不同；未跳到对应页时，请在左侧手动输入同一页码。直接滚动 PDF 不会自动切换右侧。

阅读设置。右上滑块调整双栏比例，A− / A+ 调整正文。导航按钮可跳到当前页的释义、术语、命令或案例。在空白处可用左右方向键翻页。

打印。“打印全部讲解”包含全篇中文释义、术语、参数与详解，可通过浏览器另存 PDF。打印不包含原讲义。

内容范围。核心意思用中文概括解释，术语与命令名帮助对照原页；并非整份逐句译文。标明“自拟”的案例不是原文实验数据。

版本。资料为 2020 年 ICC2 培训讲义；命令表用于读懂教材，不是当前 FC 可直接执行的脚本。具体选项、默认值和阶段行为应核实本地帮助及项目流程。

若原文区域显示失败，可点击“单独打开原文”并排阅读。重新打开 HTML 时需要再次选择原 PDF。
