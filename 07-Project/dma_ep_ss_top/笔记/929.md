PrimeTime ECO 命令和命令选项让你可以执行不同类型的 ECO。在决定修复设计规则约束（DRC）、时序设置（setup）和保持（hold）违规的顺序时，需要考虑你的设计状态和 ECO 修复目标。修复 setup 或 hold 并不会加剧 DRC（最大电容和最大转换）违规，但修复 DRC 可能会加剧 setup 或 hold 违规，因为 DRC 修复优先级最高。此外，修复 hold 可以保留 setup 的裕量，但修复 setup 可能会引入一些 hold 违规，因为 setup 是更难修复的问题。因此，通常建议先修复 DRC 违规，再修复 setup 违规，最后修复 hold 违规。如果修改次数很多，并且这些修改会干扰 IC Compiler 或 IC Compiler II 中的 ECO 布线和合法化，可以一次只做一次 setup、hold 和 DRC 修复，以减少单次操作可能引发的干扰。因此，你应该先修复在 ECO 修复过程中会导致更多修改的违规。要优先修复时序违规而非设计规则违规，可以使用 fix_eco_timing 命令并加上 -ignore_drc 选项。如果使用这个选项，命令会忽略并可能导致最大转换、最大电容和最大扇出设计规则违规恶化。默认情况下，fix_eco_timing 命令不会修复路径上存在设计规则违规的时序问题。
