add_buffer_on_route 中文详解

作用：沿指定 net 的已有物理 route 插入 buffer / inverter repeater。

最重要：新 buffer 会被放置，但不会自动 legalize；原 net 和新生成的 net 也不会自动 reroute。
按位置插-location {x y layer}
按间距插-repeater_distance
避开阻塞-respect_blockages
吸附到 site-snap_to_sites

    [-layer_cutting_distance layer_cutting_distance_list]
    [-verbose]

2. 最常用参数先看这里

参数作用你可以怎么理解
-lib_cell指定要插入的 buffer / inverter lib cell“插什么 cell”
-location指定 route 附近的目标坐标“我想在这里附近插”
-detect_layer不写 layer，由工具找最近 routing shape“层我不指定，你找”
-repeater_distance沿整条 route 按固定物理间距插 repeater“每隔多少距离插一个”
-first_distancedriver 到第一个 buffer 的距离控制第一段
-last_distance最后一个 buffer 到 load 的距离控制最后一段
-respect_blockages不在 blockage / soft macro / hard macro 内插避障
-snap_to_sites把新 buffer 吸附到最近 placement site接近合法行，但不等于完整 legalize

3. 参数详解

list_of_nets

指定需要插 buffer 的 net。若使用 -user_specified_buffers 或 -location，这里必须只指定一条 net。

-lib_cell buffer_lib_cell

指定作为 repeater 使用的 library cell。必须是 buffer 或 inverter。

如果给 inverter，工具会根据需要插入成对 inverter，保证逻辑功能不发生反相变化。

不能与 -user_specified_buffers 或 -user_specified_bus_buffers 同时使用。
-net_prefix / -cell_prefix

-net_prefix：新生成 net 的前缀，默认 eco_net。

-cell_prefix：新 buffer instance 的前缀，默认 eco_cell。

-cell_prefix 不能与 -user_specified_buffers 同时使用。

-location coordinate_list

指定 buffer 或 inverter pair 的中心位置。格式：

{x1 y1 layer1 x2 y2 layer2 ...}

例如：

add_buffer_on_route -location {100 200 METAL3} net1 -lib_cell lib/BUF

表示希望在坐标 (100,200) 附近、METAL3 上的 route 插 buffer。

这些位置必须在 route 的一定范围内，允许距离由 -max_distance_to_route 控制。

-detect_layer

不在坐标中指定 layer，由工具寻找最近的 routing shape。

-location {100 200} -detect_layer
如果两个不同 metal layer 上的 route 与目标坐标距离相同，工具会报错。手册明确建议：条件允许时，最好显式写 layer。
-user_specified_buffers

同时指定 buffer 名称、lib cell、坐标与 layer：

{name1 lib_cell1 x1 y1 layer1
 name2 lib_cell2 x2 y2 layer2 ...}

可以混合 buffer 与 inverter，但 inverter 在每条 branch 上必须成对出现。

不能与 -lib_cell 或 -voltage_area_specific_lib_cells 一起使用。

-max_distance_to_route

指定用户给出的坐标距离真实 route 最多允许多远。默认值是 5 × reference cell height。

只能和 -location 或 -user_specified_buffers 搭配。

-user_specified_bus_buffers / -bus_cell_prefix

用于 bus 多个 bit 的 buffer / inverter pair 插入。bus buffer pattern 由 create_eco_bus_buffer_pattern 创建。

附近各 bit 的 route 需要平行，并且物理环境要一致，例如 VA、blockage、macro 条件一致。

-repeater_distance

指定沿 route 插入相邻 buffer 的距离，作用于整条物理 route。

Driver ──100── BUF ──100── BUF ──100── BUF ── Load

例如：

add_buffer_on_route -repeater_distance 100 net1 -lib_cell lib/BUF
-repeater_distance_length_ratio

用总 route length 的比例表示 repeater spacing，范围 0.0 ~ 1.0。

例如 0.4 表示间距相当于总 route 长度的 40%。

-first_distance / -first_distance_length_ratio

-first_distance：driver pin 到第一个 buffer 的绝对距离。

-first_distance_length_ratio：用总 route 长度的比例表示第一段距离。

Driver ── first_distance ── BUF1 ── repeater_distance ── BUF2
-last_distance

指定最后一个 buffer 到 load pin 的距离。

... BUF2 ── last_distance ── Load

需与 -repeater_distance 或 -repeater_distance_length_ratio 搭配。

-scaled_by_layer

根据不同 routing layer 缩放 repeater spacing：

{{METAL2 0.9} {METAL3 0.8}}

公式：

D = d × L_M

d：原 repeater distance；D：缩放后的距离；L_M：layer scaling factor。

-scaled_by_width

按实际 route width 缩放间距：

D = d × w_M / w_R

其中 w_M 是该层默认宽度，w_R 是实际 route width。

-only_global_routed_nets

允许在只有 global route、尚未进行 track assignment 或 detail route 的 net 上插 buffer。

与 -scaled_by_width 互斥。

-respect_blockages

禁止 buffer 插到 placement blockage、soft macro 或 hard macro 内。

-allow_insertion_over_cell 可指定例外 macro；-dont_allow_insertion_over_cell 用于指定明确禁止的 macro。

-max_distance_for_incomplete_route

net 未完全 route 完时，规定工具的最大搜索距离。默认是一倍 repeater height。

-snap_to_sites

把新加入的 buffer 吸附到最近 placement site。

注意：-snap_to_sites 不等于完整 placement legalization。
-punch_port

物理 route topology 与逻辑 hierarchy connection 不一致时，允许工具创建 hierarchical port 来连接 buffer 后方 loads。

与 -respect_voltage_areas、-voltage_area_specific_lib_cells、-respect_gas_station 互斥。

-respect_gas_station / -max_distance_route_to_gas_station

multi-voltage / low-power 场景使用。buffer 仅允许加入指定 supply net 对应的 gas station。

-max_distance_route_to_gas_station 控制 route 与 gas station 允许的最大距离。

-respect_voltage_areas

要求插入的 buffer 遵守 voltage area hierarchy，并且物理位置位于对应 hierarchy 内。

启用后 buffer 不能插到 core area 外。

-voltage_area_specific_lib_cells

针对不同 voltage area 使用不同 buffer cell：

{VA1 lib/BUF1 DEFAULT_VA lib/BUF2}

未明确指定的 VA 使用 -lib_cell 提供的默认 cell。

-allow_physical_feedthrough_buffer

允许在指定 primary voltage area 中添加 physical-only feedthrough buffer。

-on_top_hierarchy / -honor_net_hierarchy

-on_top_hierarchy：把 buffer 加到 net 的最高层 hierarchy。

-honor_net_hierarchy：在给定 net 当前 hierarchy 内插 buffer。

-max_distance_to_spare_cell / -not_spare_cell_aware

freeze-silicon mode 使用。前者限制新 buffer 与兼容 spare cell 的最大搜索距离；默认 5 个 site height。

后者关闭 spare-cell-aware 功能。

-select_mv_buffers

开启 MV-aware buffer 选择，为每个 voltage area 指定 single-rail / dual-rail buffer。

{VA1 lib/BUFS1 lib/BUFD1 VA2 lib/BUFS2 lib/BUFD2}
-min_buffer_distance

控制 blockage 附近新增 buffer 与前一个 buffer / driver 的最小距离。

默认值为 50% × repeater_distance。

-layer_cutting_distance

按 layer 指定 repeater 输入侧和输出侧的 route cutting spacing：

{{layer1 cutting_distance_in_1 cutting_distance_out_1}
 {layer2 cutting_distance_in_2 cutting_distance_out_2}}

优先级高于 eco.add_buffer_on_route.route_cutting_space，不支持 global route shapes。

-verbose

显示更详细的执行信息。

4. 命令到底做了什么

已有 route
→
寻找目标 route 位置
→
切开原 net
→
插入 buffer
生成新 net
→
buffer 被放置
→
后续 legalize
→
后续 ECO route
手册原意：新 buffer 会被 placed，但不 legalized；原 net 和新建 net 都不会 reroute。

新 buffer 会尽量靠近输入 net 的原 route，新 net 也会尽可能沿原 route。刚插入的新 buffer 可通过 collection abor_new_buffers 查询。

5. 使用限制 / 合法性规则

  • 目标 net 不能是 PG net 或 tie net。
  • net 可以是 incomplete route，但已有 routing segments 必须彼此连通。
  • 对于未接上的 load pin，在搜索范围内必须有且只有一根候选 wire。
  • lib cell 不能是 sequential cell。
  • lib cell 必须满足 buffer / inverter 定义。
  • 命令遵守 design.eco_freeze_silicon_mode；开启时插入 cell 会带 is_fs_eco_add=true。
  • 该命令不依赖 scenario-specific 信息。

6. 官方示例

例 1：固定间距 + 第一段距离
add_buffer_on_route -repeater_distance 100 \
    -first_distance 80 net1 -lib_cell lib/BUF

第一颗 buffer 距 driver 80，之后按 100 的 route distance 插。

例 2：再控制最后一段
add_buffer_on_route -repeater_distance 100 \
    -first_distance 80 -last_distance 50 net1 -lib_cell lib/BUF
例 3：指定坐标，自动找 layer
add_buffer_on_route -location {100 200} -detect_layer net1 \
    -lib_cell lib/BUF
例 4：坐标 + layer 都明确指定
add_buffer_on_route -location {100 200 METAL3} net1 \
    -lib_cell lib/BUF
例 5：用户指定多个 buffer
add_buffer_on_route n1 \
    -user_specified_buffers {eco1 bufbd2 70 10 eco2 bufbd4 140 10} \
    -detect_layer
例 6：bus buffer
add_buffer_on_route [get_nets data*] \
    -user_specified_bus_buffers "bpuLT bufx8 x1 y1 bpuBR bufx8 x2 y2"
例 7：按 route length 比例
add_buffer_on_route \
    -repeater_distance_length_ratio 0.4 \
    -first_distance_length_ratio 0.2 \
    net1 -lib_cell lib/BUF
例 8：按 layer / width 缩放
add_buffer_on_route -repeater_distance 100 \
    -scaled_by_width -scaled_by_layer {{METAL2 0.9} {METAL3 0.8}} \
    net1 -lib_cell lib/BUF
例 9：吸附到 site
add_buffer_on_route -location {100 200 METAL3} net1 \
    -lib_cell lib/BUF -snap_to_sites
例 10：跨 hierarchy 时 punch port
add_buffer_on_route -repeater_distance 100 h1/net1 \
    -lib_cell lib/BUF -punch_port
例 11：遵守 voltage area
add_buffer_on_route -repeater_distance 100 h1/net1 \
    -lib_cell lib/BUF -respect_voltage_areas
例 12：允许 physical-only feedthrough buffer
add_buffer_on_route -repeater_distance 100 h1/net1 \
    -lib_cell lib/BUF -respect_voltage_areas \
    -allow_physical_feedthrough_buffer {VA1 VA2}
例 13：不同 VA 使用不同 lib cell
add_buffer_on_route -repeater_distance 100 net1 \
    -lib_cell lib/BUF0 \
    -voltage_area_specific_lib_cells {va1 lib/BUF1 DEFAULT_VA lib/BUF2}
例 14：Gas Station
add_buffer_on_route -repeater_distance 100 net1 \
    -lib_cell lib/BUF -respect_gas_station vdd1 \
    -max_distance_route_to_gas_station 10
例 15：MV-aware buffer
add_buffer_on_route -repeater_distance 100 net1 \
    -lib_cell lib/BUF \
    -select_mv_buffers {VA1 lib/BUFS1 lib/BUFD1 VA2 lib/BUFS2 lib/BUFD2}
例 16：保持 net hierarchy
add_buffer_on_route -location {35 66 M3} m_1/net1 \
    -lib_cell lib/BUF -honor_net_hierarchy

7. 学习总结

如果你当前主要是在做 routing ECO、长线修 transition / capacitance / timing，先掌握两种模式即可：

# 1) 手动指定插入位置
add_buffer_on_route \
    -location {X Y Layer} \
    $net \
    -lib_cell $buffer

# 2) 根据 route length 自动按间距插入
add_buffer_on_route \
    -repeater_distance 100 \
    $net \
    -lib_cell $buffer
和普通 insert_buffer 的理解区别：
add_buffer_on_route 的核心是“沿已有物理 route做 ECO”，位置选择与 net 切分和 route 几何有关，而不只是对逻辑网表简单插 cell。

推荐优先记： -lib_cell -location -detect_layer -repeater_distance -first_distance -last_distance -respect_blockages -snap_to_sites
